# 行为日志模板

将事件追加到根目录 TASK_LOG.md，填写真实 ISO 8601 时间与唯一任务 ID。下面为模板，不是已发生事件。并行任务只有在明确获准时才使用独立 records/tasks 日志。

## TASK-ID / START / 时间

- 执行者：
- 用户目标与范围：
- 文档依据：DESIGN 章节；ACCEPTANCE 编号；相关 DEC ID。
- 当前状态与前置检查：
- 计划变更文件/模块：
- 验证计划：
- 已知限制：

## TASK-ID / CHECKPOINT / 时间

- 实际行动：读取、修改、执行、外部副作用，按实质操作概括。
- 变更文件与目的：
- 检查命令、工作目录、退出码：
- 结果与证据路径：
- 失败/偏差/修订决定：
- 下一步：

## TASK-ID / END / 时间

- 状态：completed / partial / blocked / cancelled。
- 完成内容：
- 验证：命令/结果/证据；未运行项必须列明。
- 文档与实现一致性：
- 遗留事项和影响：
- 后续起点：
- 清单安排：本条之后生成快照；快照自检由生成过程终端输出或单独证据证明，不伪造提前成功。

- 实际状态检查或更正事实：
- 修订原因与后续动作：
